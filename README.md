# SatVision AI

AI-Based Satellite Image Analysis and Object Detection System using YOLOv11 and OpenCV.

## Features
- Satellite image analysis
- Object detection

## Technologies Used
- Python
- YOLO
- OpenCV

## Installation

```bash
pip install -r requirements.txt
```

## Run Project

```bash
python main.py
```

## Dataset
Place satellite images inside the `datasets` folder.

## Project Structure

```text
SatVisionAI
│
├── datasets
├── main.py
├── requirements.txt
├── README.md
```
